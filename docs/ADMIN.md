# Адмінка бота (/admin)

Адмінка — окремий модуль `admin/` на FastAPI. Публічний бот про неї не знає:
диспетчер у `app.py` передає лише запити з префіксом `/admin`.

Адреса: https://csctemplate.pythonanywhere.com/admin

## Вхід

- **Логін:** `ADMIN_USERNAME` (за замовчуванням `admin`).
- **Пароль:** `ADMIN_PASSWORD` з локального `.env`. Згенеровано автоматично; у репозиторії його немає.
- Браузер покаже вікно входу (HTTP Basic). Сторінки позначені `noindex`, щоб пошуковики їх не індексували.
- Кожна форма містить CSRF-токен, тож чужий сайт не зможе змінити налаштування від вашого імені.

Якщо `ADMIN_PASSWORD` порожній, адмінка вимкнена і відповідає 503.

## Розділи

| Розділ | Що робити |
|---|---|
| **Дашборд** | Скільки питань, режими відповідей, 👍/👎, найчастіші питання, за 14 днів |
| **Питання** | Повний журнал: час, питання, режим, оцінка студента |
| **Перевірка** | Питання без відповіді в конспекті або з 👎. Напишіть відповідь і натисніть «Зберегти» |
| **Відповіді викладача** | Список ваших відповідей. Видалити можна будь-яку |
| **Файли** | Завантажити HTML-урок, видалити свій файл, **Перебудувати індекс** |
| **Налаштування** | Фрагментів у відповіді, модель, ліміт запитів, вимкнути бота |

## Людина в циклі (human-in-the-loop)

1. Студент ставить питання. Якщо в конспекті відповіді немає або він натиснув 👎, питання потрапляє в «Перевірку».
2. Викладач відкриває питання, пише відповідь і зберігає.
3. Тепер на це саме питання (порівняння без регістру й пунктуації) бот відповідає текстом викладача, режим «Відповідь викладача».
4. Виправити або прибрати відповідь можна в розділі «Відповіді викладача».

## Завантаження уроку

1. **Файли → Завантажити HTML-урок.** Назва латиницею (наприклад `lesson_47.html`), UTF-8, до 3 МБ.
2. Натисніть **Перебудувати індекс**: бот почне шукати по новому матеріалу.
3. Файл з такою самою назвою, як у репозиторії, замінить репозиторну версію.
4. Видаляти можна лише завантажені файли. Репозиторні уроки видаляються тільки через Git.

Завантажені файли і перебудований індекс зберігаються в `RAG_DATA_DIR` (на сервері — `/home/<логін>/rag_data`), поза папкою коду. Тому наступний деплой їх не стирає.

## Налаштування

- **Фрагментів у відповіді (1–10)** — скільки фрагментів уроку бот бере для відповіді.
- **Модель OpenAI** — назва моделі. Перевіряйте, що ваш проєкт OpenAI має до неї доступ.
- **Ліміт запитів до моделі на хвилину** — захист квоти OpenAI.
- **Використовувати модель** — вимикає виклик OpenAI без зміни ключа.
- **Бот доступний студентам** — тимчасове вимкнення. Студенти бачать повідомлення про паузу.

Ці значення мають пріоритет над `.env` і зберігаються в базі даних на сервері.

Ключ OpenAI адмінка **не показує і не змінює**. Він задається тільки в `.env` (локально) і в GitHub Secrets; див. [SETUP.md](SETUP.md).

## Де що лежить

```
admin/app.py                 адмінка (FastAPI): маршрути, форми, перевірки
rag/store.py                 SQLite: питання, оцінки, відповіді викладача, налаштування
rag/runtime.py               спільний стан: індекс, налаштування, перебудова
RAG_DATA_DIR/rag.sqlite3     БД на сервері (не в Git, деплой її не чіпає)
RAG_DATA_DIR/sources/        завантажені адміном HTML-уроки
RAG_DATA_DIR/chunks.json     індекс, побудований на сервері
```

## Обмеження

- Адмінка працює в одному процесі з ботом. Після зміни налаштувань бот бачить їх одразу. Після перебудови індексу, якщо сервер запущений у кількох процесах, перезапустіть веб-апку (**Web → Reload**).
- Журнал питань зберігає текст питань студентів. Не просіть студентів писати персональні дані, або видаляйте записи вручну через БД.
- Логін і пароль працюють по HTTPS. Не відкривайте `/admin` через HTTP.
- Безплатний PythonAnywhere має ліміт CPU; адмінка легка, але масова перебудова індексу на багатьох файлах може його вичерпати.
